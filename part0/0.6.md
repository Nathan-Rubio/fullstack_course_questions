
# 0.6: New note in Single Page App diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes a note and clicks Save

    Note right of browser: spa.js handles the form submission and prevents the default action

    Note right of browser: JavaScript creates a new note object containing content and date

    Note right of browser: The note is added to the local notes array

    Note right of browser: Updates the DOM and displays the new note

    browser->>server: POST /new_note_spa
    activate server
    Note right of server: Server receives and saves the note
    Note left of server: Request body contains JSON with content and date
    server-->>browser: HTTP Created
    deactivate server

    Note right of browser: Browser stays on the same page. No reload is necessary
```
